Build the analysis panel

Join city -> county (by county_fips) and city -> CBSA state flags (by cbsa_code), compute pct_of_county and cagr.

Code 
panel <- city %>%
  left_join(
    county %>% select(county_fips, county_name, population_2020_county = population_2020),
    by = "county_fips"
  ) %>%
  left_join(
    cbsa_flags %>% select(cbsa_code, n_states, multi_state_metro),
    by = "cbsa_code"
  ) %>%
  left_join(region_lookup, by = "state_fips") %>%
  mutate(
    pct_of_county = population_2020 / population_2020_county * 100,
    cagr = (population_2020 / population_2000)^(1 / 20) - 1,
    multi_state_metro_flag = as.integer(multi_state_metro),
    region = factor(region, levels = c("South", "Northeast", "Midwest", "West", "Puerto Rico"))
  )

# regression sample: drop the 6 rows with no usable 2000 population
panel_reg <- panel %>% filter(!is.na(population_2000))

Does the annexation-reach effect on pct_of_county survive controlling for region (and metro size)? Yes on significance, but the sign is the opposite of the naive “bigger annexation reach -> faster growth” story: pct_of_county is negative and significant (p < 0.05) in all three specifications, meaning cities that already hold a larger share of their county’s population tend to have slower 2000-2020 CAGR, controlling for region and metro size — consistent with a ceiling/mean-reversion effect (there is less room left to annex or in-fill once a city already dominates its county) rather than annexation reach driving extra growth. multi_state_metro_flag is never statistically distinguishable from zero and even flips sign once region is added, so on this cross-section state-line fragmentation alone does not show up as an independent growth penalty net of region and pct_of_county — the Columbus/Cincinnati contrast below should be read as a single illustrative case, not as evidence of a general multi-state effect.

Growth vs. annexation reach (interactive)

Code 
panel_reg <- panel_reg %>%
  mutate(
    multi_state_lab = if_else(multi_state_metro, "Multi-state metro", "Single-state metro"),
    tooltip_text = paste0(
      place_name, ", ", state_name, "\n",
      "% of county pop (2020): ", number(pct_of_county, accuracy = 0.1), "%\n",
      "CAGR 2000-2020: ", percent(cagr, accuracy = 0.01), "\n",
      multi_state_lab
    )
  )

p <- ggplot(panel_reg, aes(x = pct_of_county, y = cagr, color = multi_state_lab)) +
  geom_point_interactive(
    aes(tooltip = tooltip_text, data_id = place_geoid),
    size = 2.2, alpha = 0.8
  ) +
  geom_smooth(aes(group = 1), method = "lm", se = TRUE, color = "grey30", linewidth = 0.6) +
  scale_color_brewer(palette = "Set2", name = NULL) +
  scale_x_continuous(labels = label_number(suffix = "%")) +
  scale_y_continuous(labels = label_percent(accuracy = 1)) +
  labs(
    x = "City population as % of home county population (2020)",
    y = "City population CAGR, 2000-2020",
    title = "City growth rate vs. share of home county population"
  ) +
  theme(legend.position = "bottom")

girafe(
  ggobj = p,
  width_svg = 8, height_svg = 6,
  options = list(
    opts_sizing(rescale = TRUE),
    opts_tooltip(opacity = 0.9)
  )

Columbus, OH vs. Cincinnati, OH

cc <- panel %>%
  filter(place_name %in% c("Columbus", "Cincinnati"), state_name == "Ohio") %>%
  select(place_name, state_name, county_name, population_2000, population_2020,
         pct_of_county, multi_state_metro, cagr) %>%

  mutate(
    population_2000 = comma(population_2000),
